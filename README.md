# Daggerheart_FGU_Color_Hope-Fear_Color_Selection
Allows users in Fantasy Grounds Unity under the Daggerheart ruleset to customize their 3D and chat window dice colors

Daggerheart Hope/Fear Dice Colors v1.0

This is a small Fantasy Grounds Unity extension that allows individual users to customize the colors of their Daggerheart Hope and Fear dice.

The extension only changes the colors used to display the dice. It does not affect the roll results, Daggerheart rules, dice mechanics, or the style/model of the dice.

Selected colors are applied to both:
- 3D dice rolls
- Dice results shown in the chat window

Each player has independent Hope and Fear colors. Player settings are tied to that player's Fantasy Grounds username and are saved with the campaign, so the settings persist between sessions and remain available when the player reconnects from another device using the same account/username.

The GM can also view and change the saved Hope/Fear colors for individual players.

COLOR OPTIONS
- Hue, Saturation, and Value (HSV) sliders
- Direct hexadecimal color input
- Automatic black/white die-number contrast
- Optional custom die-number colors
- Swap Text Color button for changing the configuration-window text between black and white

USAGE
Type the following command into the Fantasy Grounds chat box:

    /dhcolors

Use the window to select your Hope and Fear colors. Changes are saved automatically.

DEFAULT DAGGERHEART COLORS
Hope: #F9B70D
Fear: #251566

COMPATIBILITY
Designed for the Fantasy Grounds Unity, Daggerheart ruleset.
